# 视频转游戏素材 · 前端设计稿汇总

本压缩包包含本轮讨论生成的 **10 张 PNG 视觉设计稿**，分为设计演进和一级导航页面两组。

## 确定的产品结构

- 左侧一级导航：工作台、项目管理、视频解析、素材库、剧情脚本、导出中心。
- 主操作路径：选择项目 → 选择集数（含全部集数）→ 选择素材分类 → 查看具体素材。
- 素材分类：角色、场景、对话、音频、动作参考、分镜片段。
- 素材区支持搜索、筛选、预览及可用/待处理状态。
- 角色按项目统一管理，支持跨集关联，避免重复角色。

## 文件说明

- `01_设计演进/`：结果概览、素材分类、集数切换和六类素材的拼图参考。
- `02_一级导航页面/`：工作台、项目管理、素材库及另外三个一级页面的视觉参考。

**注意**：设计稿均为概念效果图，内容、数量、名称均为示例；尤其视频解析、剧情脚本、导出中心三张仍偏向概览/素材展示，**尚不是独立功能页的最终交互设计**。图片不是可编辑 Figma 源文件，实际开发需要按约定信息架构实现组件和交互。
