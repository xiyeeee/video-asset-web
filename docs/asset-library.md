# 素材库

素材库按项目和剧集展示提取结果，不在这里管理整单任务。分镜页和对话页都不播放原视频，原视频仍可在项目详情中播放。对话页只显示时间轨和台词。

六个页签：

| 页签 | 数据来源 |
| --- | --- |
| 分镜 | `GET /api/media/episodes/{episodeId}/assets?type=SHOT`。正式分镜按时间从上到下排成记录。没有正式分镜时，历史首帧同样往下排，并标明未分段 |
| 人物 | 现有人物素材分页。展示图片、出现时间、来源帧和大小。没有角色归组时标记「待归组」，不把素材张数当成角色数 |
| 对话 | `GET /api/media/episodes/{episodeId}/assets?type=DIALOGUE`。暂时不播放原视频，只按 `[startMs,endMs)` 画时间轨和台词，空白保留，重叠句分轨。说话人显示为「说话人 N」或「未知说话人」 |
| 背景 | 能力未开放时显示即将支持。分镜截图不会被标成无人物背景 |
| 音频 | 能力未开放时显示即将支持。后续类型为 VOICE、BGM、SFX、AMBIENCE |
| 剧情 | 能力未开放时显示即将支持。不在这里做剧情编辑 |

每个页签单独组件，并处理加载、失败和空结果。人物列表在宽屏下于右侧区域滚动，翻页留在列表上方。
