# 页面结构

左侧导航固定为六项：工作台、项目管理、视频解析、素材库、剧情脚本、导出中心。导航可折叠，当前项高亮，并尽量带上当前项目和集数参数。

## 工作台 `/`

默认首页。展示项目数、集数、素材数、已完成解析数、进行中的任务、最近项目和最近素材。新建项目、上传视频、导入小说、导出素材都会进入对应流程。点击项目卡片进入 `/projects/:projectId`。

## 项目管理 `/projects` 与 `/projects/:projectId`

列表支持搜索、创建、编辑和删除确认。详情页展示原著摘录、集数列表、播放器、分类型素材数量。上传单集、批量上传和导入 TXT 都从这里发起。集数上的「查看解析」「查看素材」进入对应页面。

## 视频解析 `/analysis`

用查询参数 `project`、`episode` 选择项目和集数。页面包含 Vidstack 播放器、四步解析状态、进度、日志、失败重试、排队任务的开始解析，以及本集素材统计。统计数字来自当前集数的素材，不是固定文案。这里没有真实 AI 接口。

## 素材库 `/assets`

这是主操作页，查询参数包括：

- `project`、`episode`（`all` 表示全部集数）
- `type`：`character | scene | dialogue | audio | motion | storyboard`
- `character`、`scene`、`subtype`、`status`、`q`、`asset`

切换集数时保留素材分类。切换项目时重置集数、角色、场景和搜索。角色按项目档案合并，`episodeIds` 记录出现过的集数。点击素材打开右侧抽屉，展示预览、时间戳、状态和演示文件下载。角色画面会标明不是 Live2D 模型。

## 剧情脚本 `/story`

按项目和集数编辑台词、说话角色、场景名和顺序。右侧显示原著摘录和当前剧情 JSON。分支、选项、双人视角、事件节点只作为「即将推出」说明，没有可点击的空按钮。

## 导出中心 `/export`

用 React Hook Form 和 Zod 选择项目、集数、素材类型、是否包含原始素材、是否包含剧情 JSON，以及三种导出格式。任务进度是模拟的。下载得到的 JSON 只包含元数据和路径约定，并写明不是 Unity 二进制资源包。
