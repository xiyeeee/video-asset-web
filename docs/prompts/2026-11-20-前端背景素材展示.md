# 前端背景素材展示开发提示词

在 `video-asset-web` 实现素材库「背景」Tab。先读 `AGENTS.md`、背景占位页、现有分镜卡片、播放器和任务中心。接口以同级 Python 仓库的 `../video-asset-ai/docs/background-extraction-contract.md` 为准。页面直接接正式 Java 网关接口。

## 实现范围

1. 通过现有鉴权和 `GET /api/media/episodes/{episodeId}/assets?type=BACKGROUND` 读取背景候选，按镜头顺序展示缩略图卡片。显示镜头编号、时间范围、来源时间和「可用候选」或「待复核」状态。人物、字幕未知时按实际状态展示。
2. 复用原视频播放器和待定位机制，点击卡片来源时间跳转到候选帧。切换剧集时重置待跳转和当前选择。多页读取固定 `sourceTaskId`，签名图片过期时重新取数据。
3. 复用能力发现、提取触发、失败重试和任务查询。处理未启用、未提取、运行中、失败和空结果，保留重跑中的旧成功素材。页面使用现有素材库布局和组件。

## 本端检查

运行 `pnpm lint` 与 `pnpm build`。通过独立测试覆盖候选状态、未知字幕、原视频跳转、签名图片、分页和剧集切换。先完成本端，无需等待 Java。

## 收到通知后集中验收

用同一真实剧集发起背景任务，从实际网关请求读取结果。核对候选图是否对应所示镜头、状态是否正确、点击能否跳到来源帧。交付剧集 ID、任务 ID 和真实页面验证结果。示例 JSON 用于协议核对和独立测试。
