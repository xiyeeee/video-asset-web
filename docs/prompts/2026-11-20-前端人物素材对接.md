# 视频转素材前端｜对接人物提取

在现有 React + TypeScript 工作台中接入人物提取。先阅读 AGENTS.md 和 Java 交付的 docs/frontend-character-extraction-api.md。沿用现有剧集选择、上传流程、播放器、请求封装和 shadcn/ui 组件。前端统一调用 Java 接口。

1. 在现有剧集操作区域接入提取入口。若 Java 已约定上传后自动发起任务，则从该流程获取任务状态。处理中防止重复点击，并显示后端返回的真实阶段或进度。
2. 查询任务并展示排队、处理、成功、失败和无素材状态。任务终止、离开页面或切换剧集时停止旧轮询。避免旧剧集的响应覆盖当前页面。失败提示按 Java 协议提供重试。
3. 在「人物」Tab 按当前剧集展示逐帧提取的人物素材。卡片显示透明 PNG 预览和来源时间，并提供下载。透明区域用便于查看边缘的底色。空结果显示「未提取到人物素材」。
4. 点击来源时间时，将当前剧集的播放器跳到 timestampMs / 1000 秒。播放器尚未加载完成时，待可定位后执行跳转。同一帧出现的两张人物图应跳到同一时刻。
5. 本轮卡片按人物素材展示，同个角色出现在多个镜头时可以有多张素材。沿用现有布局，跨镜头角色卡等 Python 提供归组结果后再接入。
6. 运行仓库现有 lint、类型检查和构建。用真实 Java 接口走通一段漫剧的提取、进度查看、图片预览、下载和原视频跳转。额外检查切换剧集时页面不会串数据。汇报联调结果及仍未验证的环节。

将本轮收到的完整提示词原样保存到当前项目的 docs/prompts/ 文件夹，文件夹不存在就创建，文件名使用 YYYY-MM-DD-前端人物素材对接.md，保留已有记录，同名时追加序号。
