# 前端分镜时间线开发提示词

在 `video-asset-web` 完成素材库「分镜」Tab 的镜头索引。先阅读 `AGENTS.md`、`docs/asset-library.md`、`src/features/assets/ShotAssets.tsx`、已有视频播放器及任务查询逻辑，保留工作区已有改动。接口以同级 Python 仓库的 `../video-asset-ai/docs/shot-extraction-contract.md` 为准。Java 联调前可用契约中两镜头数据做局部接口替身。

## 实现范围

1. 复用现有素材库和播放器。在分镜 Tab 展示原视频、按时长比例排列的分段镜头条、按时间排序的缩略图卡片。先完成分段、点击跳转和播放时高亮。每张卡片显示镜头编号、时间范围与代表图。原播放器保留连续播放控制，分段条和卡片都可通过键盘操作。
2. 使用 `GET /api/media/episodes/{episodeId}/assets?type=SHOT` 及既有鉴权。确认同类请求使用契约里的完整网关路径。只对正式分镜绘制区间；历史首帧可沿用现有预览。大于一页时固定同一 `sourceTaskId` 取后续页，集中做类型校验、排序和区间合法性处理。
3. 点击镜头用 `startMs / 1000` 跳到原视频位置，`previewTimestampMs` 对应缩略图。播放器尚不可定位时沿用已有延迟跳转机制。根据播放时间和半开区间高亮当前镜头，两个区间交界时高亮下一段。切换剧集时重置进度、待跳转和选中镜头。
4. 沿用现有任务中心、上传选项和能力发现，按 Java 的 `SHOT` 能力状态开放触发。展示加载、未提取、处理中、失败和历史首帧等状态。已有成功分镜和重新提取中的任务可以同时展示。

## 验证

- 运行 `pnpm lint` 和 `pnpm build`，用两镜头示例检查按比例布局、点击跳转、区间交界高亮、键盘操作、无正式分镜和切换剧集。
- Java 上线后用《末班车之后》的实际清单验收，从任务入口走到时间线和播放器。检查移动端可操作性、视频加载前点击、分页和过期缩略图重新取数据。汇报模拟及真实验证结果。
