你正在开发「视频转素材」项目的前端。请在现有 Live2D 工作台中新增「我的模型」页面，接入已保存模型的历史查询、预览和下载。

先阅读现有工作台、路由、API 封装、项目和角色数据结构、Live2D 预览组件，以及后端提供的接口文档。复用现有项目结构和组件。保留当前模型生成流程与页面入口。

一、页面布局

参考提供的「我的模型」设计稿，沿用项目现有的深色紫色主题。

1. 工作台顶部提供「模型生成」「我的模型」两个 Tab，右上角提供「生成新模型」入口，跳转到现有生成流程。
2. 「我的模型」主体为三栏：
   - 左栏「角色」：显示当前项目下有已保存模型的角色，展示头像和角色名。
   - 中栏「历史版本」：展示当前角色的历史版本，按最新版本优先排列，显示版本号、缩略图和保存时间。版本名称可用时展示。
   - 右栏「模型预览」：加载选中版本，提供「重置视角」「全屏」「下载模型包」。复用现有 Live2D 播放组件，预览加载后应按该模型实际具备的能力播放动作或响应交互。
3. 首次打开时默认选中第一个有模型的角色，并加载该角色的最新版本。由生成成功页跳转进来时，优先选中刚保存的版本。切换角色时默认选中目标角色的最新版本。

二、接口与状态

1. 对接后端的角色列表、版本列表、版本详情和模型包下载能力。以现有接口约定和后端文档为准。
2. 历史记录和预览入口从服务端获取。点击历史版本、刷新页面、重新进入工作台，均通过查询接口恢复模型。
3. 保留已有生成状态。后端确认模型包已保存后，才显示「已保存」和「查看模型」。点击「查看模型」进入「我的模型」并定位到刚生成的版本。
4. 分别处理首次加载、无历史模型、列表加载失败、预览加载失败和下载失败。无历史模型时提供「生成新模型」入口。预览失败时提供重试，重试只重新获取所选版本的预览资源。
5. 快速切换角色或版本时，以最后一次选择为准。释放旧模型相关的资源和监听，避免画布显示上一版或下载到错误版本。
6. 模型包下载使用选中版本。若预览地址有有效期，失效后重新调用版本详情获取可用地址。

三、验收与交付

1. 同一角色生成两次后，历史列表能分别打开 V1 和 V2。
2. 刷新页面或重新登录后，可从「我的模型」恢复已保存版本。
3. 切换历史版本只发出查询和资源加载请求。浏览器网络面板中无生成请求。
4. 预览与下载指向同一个选中版本。
5. 无历史数据、保存失败和预览失败时，页面有对应状态。
6. 交付时说明修改文件、实际调用的接口、联调结果和仍待确认的问题。
