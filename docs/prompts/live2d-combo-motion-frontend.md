你正在开发「视频转素材」项目的前端。本轮根据组合动作设计稿，实现「Live2D 工作台 → 动作库 → 组合动作」。先阅读现有路由、动作库、模型历史、Live2D 播放器和 API 封装。沿用现有深色紫色主题及组件。

1. 页面和入口
   在动作库内提供「单个动作 / 组合动作」切换。组合动作列表支持新建、打开、播放已保存组合。编辑页左侧是可搜索的动作素材列表，右侧是模型预览及模型版本选择，底部是多轨时间轴，右上角是「保存组合」。
   从「我的模型」进入时可以带入选中的模型版本。打开已有组合时，恢复它保存时绑定的模型版本。

2. 时间轴交互
   首版实现脸部、头部、口型、台词音频四条轨道。支持添加、移动、裁切和移除片段，支持点击刻度定位播放头。轨道共用同一把时间尺，片段允许在不同轨道重叠。
   前端内部按整数毫秒处理时间，界面显示秒。给空轨道明确的添加入口。对于缺少参数的动作，在库里显示缺失能力，并在时间轴中定位存在冲突的片段。

3. 同步预览和保存
   根据 Java 接口提交当前草稿进行编译，使用现有 Live2D 播放器加载编译产物。模型和音频由同一个播放时钟驱动，支持播放、暂停、定位和循环。暂停和切换模型时停止旧播放并释放相关资源。
   编辑草稿后标记预览待更新。只接受与最新草稿匹配的编译响应，避免快速编辑时旧响应覆盖当前预览。保存时使用当前草稿对应的编译结果，保存成功后回到列表或留在编辑页显示已保存状态。
   处理模型加载失败、编译失败、参数冲突、缺少绑定、保存失败和未保存离开。接口以 docs/live2d-combo-motion-api.md 为准。

4. 验收
   选一份已保存模型，添加 0–3 秒微笑、0.5–1.3 秒点头，并让台词音频和口型从 0.2 秒对齐开始。在第 1 秒能看到三个动作同时生效。拖动播放头后，模型姿态和音频位置一致。
   保存「微笑点头说话」，刷新后从组合动作列表重新打开，能重播、修改时间轴并再次保存。用真实模型和真实编译产物完成联调。
