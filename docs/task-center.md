# 任务中心

任务中心在 `/tasks`，用来查看和重试 AI 提取任务。素材库不再承担启动任务和展示任务日志。

列表优先请求 `GET /api/ai/v1/tasks`。该接口尚未提供时，改为读取当前账号的项目和剧集，再查询每集最新的人物提取任务。因此刷新后仍能看到已经创建的人物任务。没有人物任务的剧集显示在「尚未创建提取任务」，可以手动发起人物提取。

状态直接使用后端结果，并映射为：

- `PENDING` 排队中
- `RUNNING` 运行中
- `SUCCEEDED` 显示为 `SUCCESS` 已完成
- `FAILED` 失败

现有人物任务没有百分比，也没有开始时间。页面展示阶段和已抽帧、已检测人数，不估算进度。分镜、对话、背景、音频、剧情在人物任务详情里标为「暂不支持」。

运行中的任务每 3 秒重新读取，进入终态后停止。读取失败时可以重试。失败任务调用已有的人物重试接口；统一重试接口 `POST /api/ai/v1/tasks/{taskId}/retry` 可用时优先使用。本轮不提供取消运行中任务。
